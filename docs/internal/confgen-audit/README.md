# ConfFlow 构象生成策略评估

评估日期：2026-09-30。范围仅为 ConfFlow 的 V4 `ConfgenExecutor`、扭转/碰撞函数及独立 confgen 的对应实现。

## 结论

当前模块适合生成**用户指定无环可旋转键的扭转候选**，不能据此宣称通用构象搜索可靠、全面，也不能把输出直接当作已验证的低能极小点。小型烷烃在合适起始构象、完整指定旋转轴和后续优化的条件下表现良好；环系、化学键类型、起始相位、重复采样及大空间搜索仍存在明确限制。

本次修复两个直接影响正确性的缺陷：V4 半径列表为空，以及无关连通分量被一起旋转。其余策略限制记录在下文，未改为新的搜索算法。

## 策略及保证边界

V4 从 XYZ 距离及共价半径推断无键级邻接图；用户显式提供 `chains`，链上每对相邻原子都成为旋转轴。默认以输入结构为起点，枚举相对增量 0°、120°、240°，可用 `chain_steps` / `chain_angles` 改写。组合旋转后进行非常宽松的碰撞过滤，最后可按固定 seed 随机截取 `max_conformers` 个候选。

- 对正确识别的无环桥边，刚体旋转能保留局部键长；本次戊烷实测最大键长变化约 1.3×10⁻¹⁵ Å。
- 环内键独立旋转会破坏闭环，V4 因而明确报错；排除环键后只保留输入的环构象，没有环翻转或环褶皱搜索。
- V4 不做预优化，`optimize=true` 明确失败；不计算能量，不按能量选择，也不在生成阶段按 RMSD 去重。后续优化和 refine 必须作为独立步骤安排。
- seed 只影响超出数量上限时的抽取；不截取时，更换 seed 不会扩充网格或改变初始相位。
- 独立 confgen 使用同类手工扭转策略和惰性组合迭代；其可选 MMFF94s 优化未检查收敛返回值，部分优化异常也被继续处理，不能把该选项视为成功优化的保证。

代码入口：[`confgen_executor.py`](../../../confflow/execution/confgen_executor.py)、[`torsion.py`](../../../confflow/science/torsion.py)、[`generator.py`](../../../confflow/blocks/confgen/generator.py)。

## 可复现实测

环境 RDKit 2026.03.4；显式包含氢原子，固定生成/参照种子。脚本直接调用正式 V4 executor，不通过 JobDesk。

```bash
PYTHONPATH=/opt/ConfFlow .venv/bin/python docs/internal/confgen-audit/benchmark.py \
  --out /tmp/confflow-confgen-audit-reproduce
```

完整结果见 [`results.json`](results.json)，方法见 [`benchmark.py`](benchmark.py)。MMFF94s 能量是力场代理值，单位 kcal/mol，不能代表量化能量真值。

| 实测 | 结果 | 含义 |
|---|---|---|
| 丁烷起始二面角 0°，步长 120° | 输出 0°、−120°、120° | 网格保留重叠相位，未直接取到通常的交错区域；后续优化可能恢复，但生成阶段没有保证 |
| 丁烷起始二面角 180°，步长 120° | 输出 180°、60°、−60° | 相同配置在不同起点采到的区域明显不同 |
| 丁烷指定整条碳链 | 27 个候选，重原子 RMSD 0.1 Å 下仅 3 个代表 | 端基旋转增加数量，不能等同于增加骨架覆盖 |
| 丁烷重复指定同一键 | 9 个候选，仅 3 个重原子代表；cap=2 的 12 个 seed 中 3 个只选出 1 个代表 | 重复维度浪费搜索与输出额度；截取前需要去重 |
| 戊烷 120° / 60° 网格 | 分别 9 / 36 个候选；经额外 MMFF 优化全部收敛，均覆盖参照的 7/7 个低能扭转区域 | 小型无环烷烃结果积极，结论依赖额外优化，不能推广成通用完整性证明 |
| 戊烷原始候选 | 120° 网格最高能量 252.62；60° 网格最高 815.64；均未被碰撞过滤删除 | 过滤通过远不等于合理低能结构；加密采样也会增加很差的候选 |
| 反式 2-丁烯指定中心双键 | 输出约 180°、90°、0° | 双键被当作普通旋转轴，能产生扭曲双键和另一几何异构体，不能当作同一分子的正常构象集合 |
| 环己烷指定环键 | 明确失败 | 能防止撕裂环，但没有覆盖椅式、船式等环构象 |
| 丁烷 + 远处水，转动丁烷键 90° | 修复后水位移 0；原选择逻辑下最大约 5.44 Å | 多片段几何正确性缺陷已修复 |

戊烷参照是 ETKDGv3 生成 200 个起点并全部 MMFF94s 优化后的集合。低能窗口为参照最低值 +3 kcal/mol；用有序两二面角最接近 −60°、60°、180° 的组合标记区域。7/7 是相对这次参照的覆盖率，不是全部构象数，也不是对称性约简后的化学独立数。重原子去重采用固定原子标签的 Kabsch RMSD，不作对称性排列搜索。未系统验证大分子、带电体系、金属配合物、质子化态、互变异构体或全部立体化学情形。

## 已修复的正确性缺陷

1. `science.bonds.covalent_radii` 循环获得半径后漏了 append，最终返回空列表。四碳测试中所有原子对都在三键以内，碰撞计算跳过，掩盖了问题；正常含氢分子或更长碳链会访问空列表并失败。补齐逐原子半径，加入显式氢/戊烷回归。修复前证据见 [`before-radius-fix.json`](before-radius-fix.json)。
2. 旋转侧选择使用 `dist_near <= dist_far`，不连通原子两侧距离均为无穷哨兵，错误进入旋转集合。V4 与独立 confgen 均改成严格较近 `<`，无关片段保持原位。独立复现见 [`fragment-before.json`](fragment-before.json)，其中只临时恢复旧的选择条件并保留正确半径，以隔离此缺陷。

V4 executor contract 从 v1 升为 v2，以使绑定身份反映计算语义变化，防止旧结果被当作修复后输出复用；同步更新边界 fixture。回归见 [`test_confgen_scientific_regressions.py`](../../../tests/v4/test_confgen_scientific_regressions.py)。

## 仍需改进的策略问题

按对科学结果的影响排序：

1. **化学允许的旋转轴。** 邻接图没有键级，不能区分单键、双键、芳香键、酰胺或共轭限制。需要可靠分子图输入和化学约束；在此之前必须人工审查 chains，不能直接把全骨架链当成可旋转键列表。
2. **覆盖起始相位及环自由度。** 默认 120° 增量依赖输入二面角；即使改成 60°，30° 起点仍会保留半步偏移。应结合目标绝对二面角、多起点和化学扭转先验；环系需要独立采样路径。ETKDGv3 可作为独立候选来源，官方说明包含经验扭转、环/大环扩展：[RDKit Book](https://rdkit.org/docs/RDKit_Book.html)。任何单一方法都不提供通用全局最低能保证。
3. **优化、去重与能量筛选。** 删除重复旋转轴，候选优化后按合理的 RMSD/扭转与对称性去重，按能量窗口和多样性保留，再做最终量化优化、收敛/结构检查和需要时的频率验证。不能用候选数或碰撞通过率代替覆盖度。
4. **碰撞过滤定义。** 默认以共价半径和 0.65 系数过滤，且完全忽略拓扑间距 ≤3 的原子对，包括 1–4。它只是灾难性重叠粗筛，不是范德华排斥模型。人工固定四原子链、端点间距 0.05 Å 的 helper 实测不会报 clash；此项是函数级示例，未声称该几何会通过完整的距离拓扑推断。改进时应避免把正常 1–4 相互作用当成必须删除的碰撞，也应拒绝严重不合理结构。
5. **组合规模和截取策略。** V4 `list(product(...))` 一次性分配全网格，并保存全部通过的坐标，完成后才做 cap。15 个三点轴是 14,348,907 点，20 个是 3,486,784,401 点；`max_conformers` 不是计算预算。需惰性遍历/预算控制、对独立轴去重和多样性保留。过滤失败的 continue 路径也应检查取消信号。
6. **结果证据。** 报告应补充输入图/键级依据、角度列表、有效独立轴、去重前后数量、截取数量、优化收敛率、能量窗口和多起点新增低能构象率，以便区分成功执行与足够覆盖。

## 验证

修复前相关现有测试 126 项通过，说明原测试不能证明真实分子的可靠性。修复后新增 4 项回归，检查半径完整性、显式含氢丁烷/戊烷、多个连通分量的几何保持以及独立实现的片段选择；同时运行 confgen、碰撞、参数、refine、V4 executor、绑定和边界相关测试，最终 **208 项通过**（另有两个已有 Pydantic schema 字段警告）。Ruff 检查和 `git diff --check` 通过。基准本身再次运行并保存上述 JSON。
