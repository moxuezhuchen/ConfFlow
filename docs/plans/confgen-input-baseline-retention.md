# ConfGen 输入基线保留修复计划

## 目标与范围

当前 `a27164a` 已把输入作为第一条搜索优化，但输入仍与普通候选共享可变去重池，
而 release 只处理受约束能量窗内的候选。这样无法长期保存独立输入基线，也可能先按
受约束能量淘汰输入，漏掉它在最终约束状态下的低能结果。

本次建立独立输入基线生命周期，完成实现与回归；不启动 CREST 或竞争排名，不改配位
化学判据，不实现完整搜索状态续跑，不强制原始坐标永远进入最终能窗。

## 保留规则

1. 原始输入作为单独产物永久留档：坐标、原子顺序、拓扑、计算参数和后端信息。
   原始坐标没有优化能量，不混入最终构象集合。
2. 输入仍先审计、优化，占用一次搜索预算。将收敛且通过审计的结果复制为独立基线，
   不能因去重池替换代表构象而改变；普通搜索池仍正常去重。
3. release 开启且约束有变化时，独立基线优先从**原始输入**直接完成最终约束状态的
   优化与审计，不受搜索能窗筛选限制。仅对受约束优化结果做 release 不等于独立零搜索
   基线，因为中间阶段可能已经改变盆地。只有起始坐标与约束都一致时才复用调用；
   搜索优化后的输入若已改变坐标，其正常 release 是不同路径，可以保留。
   release 关闭或无需释放时，复用对应约束状态的有效输入结果。
4. 保存最终输入基线，即使它被最终能窗排除；有效且同约束状态的最终基线同时作为
   普通候选参与最终去重和能窗筛选。因此有可比有效基线时，最终最低能不应劣于它。
5. 不收敛、审计失败、取消或时间不足时明确状态，保留最后一个有效阶段，不将受约束
   能量误作已 release 的最终能量。没有可比基线时不宣称满足最低能保证。
6. 增量检查点携带基线进度；worker 原子更新独立 `input_baseline.json`，并登记产物，
   中断时仍可读取原始输入及此前完成的有效基线。

## 预算与审计

- 输入初始化计入 `budget`；基线 release 计入 release 总调用与总调用统计，同时单列
  基线 release 成本，不能重复计数或隐藏计算。
- 遵守现有软时限和取消机制；无法抢占单个正在运行的后端调用。
- 输出原始审计、搜索优化、基线 release、最终可比性和能窗/去重去向，明确能量所对应
  的约束状态。基线数据与最终输出集合分开。

## 执行分工

- subagent：科学层基线记录、release 调度、预算/可比性统计及针对性回归。
- 主代理：执行层原子产物、产物登记、集成测试、真实回归、文档与集成审查。
- 发现额外缺陷时在授权范围内修复；本计划无需再次确认才开始执行。

## 验收

1. 输入在搜索能窗外，但 release 后成为低能构象：仍得到基线，最终最低能不高于它。
2. 基线最终能量偏高：可以不出现在最终集合，但独立产物仍包含有效基线和排除说明。
3. 去重池替换代表、release 去重合并，都不改写独立输入基线。
4. 同一输入不产生无谓重复 release；搜索次数、release 次数与基线子计数一致。
5. release 失败、软时限、取消、预算1、release关闭/无需释放均有明确状态；失败不清空
   已有有效快照，不把不同约束状态能量混比。
6. worker 集成覆盖原始留档、增量更新、取消后保留、最终产物与 artifact 注册。
7. ConfGen、架构策略、Mypy、Black、Ruff及修改行覆盖率≥85%通过；LOC上限仅按本次
   实测增量更新并记录理由，沿用现有计划中小幅增量无需另行确认的规则。
8. 使用既有 DILQAQ 输入和同预算真实 GFN2-xTB 闸门，归档新日志，不覆盖旧失败记录；
   确认输入盆地保留、基线可比性、预算与反馈仍成立，不据此做竞争力结论。

## 执行状态

已完成实现和本地验证；提交、合并状态以Git记录为准：

- 科学层新增独立、只读的 `InputBaseline` 记录，优先从原始输入评价最终基线。
- worker 原子保存 `input_baseline.json` 并注册 `search_input_baseline`，取消保留此前阶段。
- 430项ConfGen测试、327项架构策略测试通过；本次修改可执行行112/114覆盖（98.25%）。
- 全项目Mypy（188个源文件）、Black、Ruff、差异检查通过。
- DILQAQ真实GFN2闸门通过18项断言：最终基线与独立输入优化同能，最低最终输出比基线
  低约0.00010 kcal/mol；8次搜索+3次最终阶段优化，其中基线子计数1次；8个检查点。
- 真实回归墙钟91.48秒、CPU84.71秒，包含外部独立输入优化；没有启动竞争测试或CREST。
