# C1 评估材料 — 统一 refine 与 ConfGen 的默认 `bond_scale`（1.2 对 1.15）

状态：**仅供评估，未动任何代码，等用户决定。** 材料来自只读实验（`main` + A2-b `801ad07`）。

## 1. 现状
- refine 默认 `bond_scale` 1.2（`REFINE_DEFAULT_BOND_SCALE`），ConfGen 默认 1.15（`tolerances.bond_scale`）。
- refine 没有声明 `topology_bonds` 时：先用记录自带的 `working_topology`，否则按 1.2 几何感知；ConfGen 用 1.15。

## 2. 证据
**(a) 感知键数差异（`perceive_adjacency`，见 A2 报告）**：普通有机分子（苯、丁烷三种构象、丁醇二种、叔丁醇、甲苯）1.15 与 1.2 完全一致；TS1 的全部 8 个结构（122 原子）在 1.2 下多出一条 `O74–C79`，1.15 下没有。这条键很可能是反应坐标上的 FORMING/BREAKING 键。

**(b) 对 refine 结果的实际影响（TS1 的 8 个结构，阈值 0.25 Å）**：

| `bond_scale` | `mapping_budget` | 保留 | 被丢弃 | 未决比较（`unresolved`）数 |
| --- | --- | --- | --- | --- |
| 1.15 | 1000（默认） | 7 / 8 | `ts1_original_plus_F1-F6`（与 `ts1_original` 重复，RMSD 0.0000） | 多（`mapping_budget_exhausted`） |
| 1.2 | 1000（默认） | 7 / 8 | 同上 | 多（同上） |
| 1.15 | 200000 | 7 / 8 | 同上 | 0 |
| 1.2 | 200000 | 7 / 8 | 同上 | 0 |

- **两种尺度给出的保留集合与被丢弃的结构完全相同**；多出的 `O74–C79` 在这个数据集上没有改变 refine 的任何判定。
- 另一个发现（与 C1 无关，但值得知道）：在 122 原子的 TS1 上，默认节点预算 1000 会让大量成对比较停在 `mapping_budget_exhausted`（两个结构都保留并写 note），提高到 200000 后全部解决且仍是 2 秒量级。

**(c) A2-b 字段的用法**：A2-b 的 `connectivity of …` note 只在同一组内键集合不同的结构之间产生。TS1 的 8 个结构在两种尺度下组内键集合都一致，所以没有产生该 note；也就是说，本数据集没有结构在"结构之间"表现出连接差异，`O74–C79` 的差异只存在于"尺度之间"。

## 3. 没有覆盖到的
- 只有 TS1 一个 TS/配合物的结构集（8 个结构）。TS2（124 原子，含 Al 中心）的夹具只在本地研究分支 `research/realization-handoff` 上，不在 `main`，所以没有测。
- 没有"优化后连接真的变了"的真实结构（需要真实优化轨迹）；A2-b 上线后才有字段可以统计。

## 4. 方案选项（不是建议，供你选）
| 方案 | 内容 | 影响 |
| --- | --- | --- |
| C1-a | refine 默认改为 1.15（与 ConfGen 一致） | 在 TS1 上结果不变；对其它体系可能少一条边的保持约束 |
| C1-b | ConfGen 默认改为 1.2 | 会改变 ConfGen 的拓扑感知，影响所有 ConfGen 输出与引擎报告（需要重新捕获检查点） |
| C1-c | 保持两个默认值，但文档写明差异，并建议 TS/配合物体系显式声明 `topology_bonds` | 零改动 |
| C1-d | refine 总是从上游记录继承 `working_topology`（现有机制），只在没有时用默认值 | 本来已是这样；只需要文档明确 |

在现有证据下，统一默认值不会改变 TS1 上的任何结果；唯一明确的风险点是其它含配位键的体系，需要更多数据。
